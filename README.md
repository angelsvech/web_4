# Ячейка — учебное бронирование шкафчиков на вокзале

Небольшой адаптивный сайт на HTML, CSS и ванильном JavaScript. Ничего устанавливать не нужно.

## Как запустить
1. Распакуйте архив целиком.
2. Откройте `index.html` в современном браузере (Chrome, Edge, Firefox или Safari).
3. Выберите свободную ячейку на схеме или в списке, задайте время, введите имя и нажмите «Забронировать».
4. «Мои брони» открывает сохранённые записи. Отмена освобождает ячейку.

Для максимально надёжной работы `localStorage` можно запустить папку через локальный сервер редактора, например расширение Live Server в VS Code. Сборка, npm и серверная часть не требуются.

## Что реализовано
- 12 шкафчиков трёх размеров, собственная схема с интерактивными кнопками;
- два фильтра: размер и максимальная цена за час;
- синхронный выбор между схемой и списком;
- занятые ячейки нельзя выбрать; состояние понятно обозначено текстом и оформлением;
- расчёт суммы для 1–24 часов, проверка имени и срока, защита от повторной брони занятой ячейки;
- список «Мои брони», отмена и освобождение шкафчика;
- сохранение броней в `localStorage`, восстановление после обновления;
- сброс демо с подтверждением;
- адаптация для мобильных экранов, доступные подписи и видимый клавиатурный фокус.

## Важно
Это учебное демо. Бронирования сохраняются только в этом браузере. Реального оборудования, оплаты, регистрации и серверной базы данных нет. Два шкафчика изначально заняты для демонстрации.

## Файлы
- `index.html` — структура страницы
- `styles.css` — стили и адаптивная вёрстка
- `app.js` — логика интерфейса и сохранение
- `assets/locker-hero.png` — сгенерированная иллюстрация для шапки
